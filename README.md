# Dushyant Patidar — Developer World

A cinematic, story-driven developer portfolio built as an interactive digital experience.

## Tech Stack

- React 19 + TypeScript + Vite
- Three.js + React Three Fiber + Drei + Postprocessing
- GSAP + ScrollTrigger
- React Icons, React Fast Marquee, Vercel Analytics

## Getting Started

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (typically `http://localhost:5173`).

## Scripts

- `npm run dev` — Start development server
- `npm run build` — Production build
- `npm run preview` — Preview production build
- `npm run lint` — Run linter

## Customization

Edit centralized data files in `src/data/`:

- `profile.ts` — Personal info and links
- `projects.ts` — Lab experiments and case studies
- `skills.ts` — Tech constellation and core nodes
- `journey.ts` — Timeline milestones and navigation

## Deployment

```bash
npm run build
```

Deploy the `dist/` folder to Vercel, Netlify, or Cloudflare Pages.
